## 目录说明

+ `labX`是第`X`次实验的指导材料、代码和PPT的文件夹。
+ `labX/README.md`是第`X`次实验的要求、指导的文档。
+ `本科生实验报告模板.docx`是报告的模板。

## 项目协作

本目录提供理论课实验的指导，但每个理论课实验的做法都有很多种，欢迎各位同学提交与实验指导不同的实现方式。

提交方式

- Fork 本仓库
- 进入对应实验目录，新建README_XX.md 文件
- 提交到自己的仓库
- 新建 Pull Request

如果不熟悉 git 的同学可参考 [廖雪峰的git教程](https://www.liaoxuefeng.com/wiki/896043488029600)
